# Open Sila brand

Sila is صلة, Arabic for *connection*. The symbol is the letter ص drawn as a single wire that ends in a port. The wordmark uses the same monoline wire with round caps, and the port and the dot on the *i* share the ember colour.

## Files

All files are in [`logo/`](logo). `-color` versions use ink and ember for light backgrounds, `-color-dark` versions use white and ember for dark ones, and versions without a suffix are one colour.

| File | Use |
| --- | --- |
| `open-sila-horizontal-*.svg` | Default lockup: README, website, docs |
| `open-sila-stacked-*.svg` | Square spaces: social cards, splash screens |
| `open-sila-symbol-*.svg` | Avatars, or when the name is already nearby |
| `open-sila-symbol-small-*.svg` | Below 48 px; a heavier wire keeps the loop open |
| `open-sila-app-icon.svg` | Favicons, app icons and unknown backgrounds |
| `open-sila-wordmark.svg` | The name on its own |

## Colour

| Name | HEX | Use |
| --- | --- | --- |
| Ink | `#0E1016` | The wire and wordmark on light backgrounds, the app icon tile |
| Ember | `#FF6A3D` | The port and the dot on the *i* |
| White | `#FFFFFF` | The wire and wordmark on dark backgrounds |

When only one colour is available, the whole logo uses that colour, the port included.

## Usage

- Keep clear space around the logo equal to the port's diameter.
- Minimum sizes: symbol 16 px (small symbol), horizontal lockup 96 px wide, stacked lockup 64 px wide.
- Don't rotate or flip the symbol, recolour the wire or the port, add effects, retype the wordmark in a font, or stretch the lockups.
