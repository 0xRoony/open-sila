# Changelog

All notable changes are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-29

First public release.

### Added

- Visual editor with typed ports, value conversion, multi-wire text inputs, command palette, outline, sticky notes, align and distribute, undo and redo, and version history.
- 217 nodes: 97 for Discord, 66 for Telegram and 54 shared.
- Database models backed by Prisma for SQLite, PostgreSQL, MySQL, MongoDB, SQL Server and CockroachDB.
- Local runner with crash restarts, run history with per-node inputs and outputs, network capture and Manual run triggers.
- Export as a standalone Node.js project with Docker, Railway and Fly.io configuration, or as a `.sila.json` project file.
- REST API, MCP endpoint and the `sila` CLI, with read-only and read-write API keys.
- Encrypted local storage for projects, secrets and keys.
- 18 templates.
